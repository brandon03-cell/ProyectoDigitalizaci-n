# IKEA · Presentación Web Pro

Presentación interactiva sobre la transformación digital de IKEA.

## Estructura

```
ikea-presentation/
├── index.html
├── styles.css
├── script.js
└── multimedia/
    └── IkeaLogo.svg.png   ← coloca aquí tu logo
```

## Uso

Abre `index.html` directamente en el navegador (Chrome/Edge/Firefox recientes).

## Navegación

- **Teclado**: ↑↓ ←→ · PageUp/PageDown · Espacio · Home/End
- **Ratón**: rueda del ratón, flechas en pantalla, índice lateral
- **Táctil**: swipe vertical

## Easter eggs felinos

- 🐾 Hay una huella en la portada y otra en la diapositiva final · clic
- 🐱 Cada 25-60 segundos un gato cruza la pantalla por abajo
- ⌨️ Secuencia Konami (↑↑↓↓←→←→) desbloquea una lluvia de gatos
- 🐈 Abre la consola del navegador para un saludo
